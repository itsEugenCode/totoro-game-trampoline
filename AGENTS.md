## Описание

Личный проект. В каталоге `unity/` лежит проект редактора Unity 6000.6.5f1.

## Содержимое

- `AGENTS.md` — этот файл
- `README.md` — описание проекта для GitHub
- `.gitignore` — исключения git, включая служебные каталоги Unity
- `unity/` — проект Unity
- `openspec/` — изменения и требования OpenSpec
- `requirements/ui/art.md` — задание на рисунки

## Правила и скиллы

Проект — папка `ai/` в корне проекта: правила в `ai/rules/`, скиллы в `ai/skills/`, остальные слоты (`mcp/`, `hooks/`, `commands/`, `subagents/`, `plugins/`) — свои папки рядом. Папку заранее не создавать: файлы появляются, когда eg просит записать. Канон: harness `local-harness.md` и harness `readme.md`.

## Где упоминается

Файл по пути нигде не цитируется.
