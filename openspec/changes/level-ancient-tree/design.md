# Design — уровень «Древнее дерево»

> **Статус:** зоны 2–5 из этого документа сняты вместе с их OpenSpec change. Ниже — черновик до пересмотра; канон сейчас — только `zone-1-forest-glade`.

## 1. Цель игрока

**Восстановить свет на верхушке древнего дерева.**  
Игрок поднимается по лесу, находит светящиеся семена, доносит их до гнезда на верхушке; по мере этого загораются огоньки, меняется освещение леса, вдали открываются намёки на новые места.

Успех — не счёт очков, а **завершённое путешествие** и видимый отклик мира.

## 2. Основной цикл

```text
исследовать → упёрться в преграду → найти способ выше
→ отскок / прыжок / реакция окружения → новый участок → повторить
```

| Фаза | Что чувствует игрок |
| --- | --- |
| Исследование | Лес живой, есть детали без UI |
| Преграда | Ветка, высота, узкая опора, закрытый цветок |
| Решение | Живот духа, траектория в воздухе, сильное приземление |
| Награда | Семя, короткий путь, платформа, проход |
| Продвижение | Камера и территория раскрывают следующую зону |

Без текстовых инструкций: подсказки — **геометрия, свет, анимация, звук** (звук — по возможности прототипа).

## 3. Пять зон

| # | Имя | Длительность | Задача зоны | Ключевое содержание |
| --- | --- | --- | --- | --- |
| 1 | Лесная поляна | 1–2 мин | Научить отскоку без текста | Семя на земле; ветка выше обычного прыжка; спящий лесной дух (батут) |
| 2 | Грибная тропа | ~2 мин | Траектория и выбор пути | Развилка: верх = редкое семя, низ = длиннее и безопаснее; узкие опоры, воздух |
| 3 | Сонные цветы | 2–3 мин | Мир реагирует на прыжки | Цветки раскрываются после сильного приземления; платформа; один поворачивается к свету; проход за цветком |
| 4 | Сломанная ветка | ~2 min | Проверка навыков в новой форме | Завал на прямом пути; обход через верхние корни; опционально кач/прогиб платформы |
| 5 | Верхушка дерева | 1–2 min | Награда и closure | Гнездо, «возврат» семян, огоньки, свет леса, дух внизу меняет позу |

Детальная геометрия, списки объектов и acceptance — в **отдельном change на каждую зону**.

## 4. Новые взаимодействия (три системы прототипа)

### А. Живое окружение

- Цветы раскрываются (зона 3).
- Грибы могут давать мягкий импульс или только визуальную «пружину» (зона 2 — уточнить в change).
- Ветки качаются / платформа прогибается (зона 4).
- Светлячки реагируют на близость (зоны 2–5, минимум одно событие в зоне 5 или 3).

Подсказка игроку — **движение и свет**, не pop-up.

### Б. Альтернативные маршруты

- Явная развилка в зоне 2; скрытая ветка за цветком в зоне 3.
- Не все семена на главной линии; без 100% collectibles для победы (прототип).

### В. Безсловные микро-истории

- Одно короткое событие на уровень в первом проходе (например: испугнутый светлячок ведёт к тайному проходу **или** существо тащит семя к «домику»).
- Не обязательно награждает очками; важен **неожиданный момент**.

Конкретное событие выбирается в change зоны 2 или 3, чтобы не дублировать.

## 5. Условия завершения

- Игрок **достигает гнезда** на зоне 5.
- **Собранные в сессии семена** (через существующий collectible-счёт или зонный tally) визуально «возвращаются» в гнездо (анимация / последовательность огоньков).
- **Огоньки загораются по очереди**; освещение сцены смещается к тёплому / вечернему «здоровому» лесу.
- **Вдали** видны силуэты или огни новых областей (parallax / статичный арт).
- **Лесной дух** внизу (зона 1) слегка меняет позу или снова засыпает — связь начала и конца.

Поражения нет; падение — возврат к checkpoint (наследие `first-level` / зоны 1).

## 6. Ограничения прототипа

| В scope | Вне scope |
| --- | --- |
| Одна playable-сцена, последовательные зоны | Несколько сцен, loading между зонами |
| Бег, прыжок, воздух, отскок Тоторo, collectibles | Бой, HP, враги |
| Семена = collectibles сессии, без инвентаря | Инвентарь, крафт, save между запусками |
| Простые триггеры окружения (цветок, кач, огоньки) | Сложный квест-граф, диалоги |
| Расширение `CameraController.useBounds` по мере роста | Новая камерная система |
| Placeholder-арт допустим | Полный art pass |

## Decisions

- **Один дух на уровне** в зоне 1 (Тоторo / спящий лесной дух); в зоне 5 — только реакция, второй bounce не вводится.
- **Победа не требует всех семян**; редкие семена — для исследователей.
- **Новые механики** (цветок, кач) — минимальные MonoBehaviour + Inspector, без общего «QuestManager».
