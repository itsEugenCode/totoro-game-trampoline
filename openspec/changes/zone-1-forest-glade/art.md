## Перерисовать в первую очередь

### `GladeBack.png` — без пустот в кадре

Текущий файл **1920×1080** в мире ≈ **15×8.4** (PPU 128). Камера ortho 6 + отскок смотрит на область примерно **~32×18** мира → картинку приходится сильно увеличивать (размытие / пустоты по краям).

| | |
| --- | --- |
| Файл | `GladeBack.png` (заменить) |
| Размер | **3840×2160** (в мире ≈ **30×16.9** при PPU 128; хватает на bounds и bounce без гигантского scale) |
| Фон | **сплошной** (это картина, не прозрачный) |
| Pivot | центр |
| Содержание | Дневная лесная поляна, низ — светлая трава/поляна, края — стволы и листва, запас неба/крон **сверху** под высокий отскок. Без персонажей, без Тоторо, без девочки, без UI/текста. |

Минимум, если 3840 тяжело: **2560×1536** (≈20×12) — лучше 1920×1080, но для bounce всё ещё нужен небольшой scale.

### Промпт (скопировать во внешнюю ИИ)

```text
Уютная 2D-игра, вид строго сбоку. Мягкие формы, пастель, сказочный лес. Нарисованный фон, не фото и не 3D. Без текста, без рамки, без UI, без водяных знаков. Без персонажей.

GladeBack.png — 3840×2160, фон СПЛОШНОЙ. Мягкий дневной лес: внизу светлая поляна (место для игрока и спящего духа), по краям стволы и листва, сверху кроны и запас неба под высокий прыжок. Композиция шире и выше обычного экрана 16:9, чтобы при боковой камере и высоком отскоке не было пустых полей. Без Тоторо и без девочки.
```
