# Proposal

## Why

Нужна законченная **финальная лесная поляна**: исследовать, собрать 5 огоньков (земля → низкий корень → отскок от духа → высота), увидеть пробуждение и тропинку дальше — без текста и без новых core-систем.

## What Changes

- Геометрия поляны: вход, дух, корни-платформы разной высоты, 5 огоньков, запас по высоте под bounce.
- Прогресс 5/5 через существующий collectible tally.
- Финальная sequence (один раз): огоньки → дух → чих/пыльца → преображение → светящаяся тропинка.
- Дыхание духа во сне и лёгкая реакция на bounce (без пробуждения до 5/5).
- Тропинка = выход/указатель; отдельная следующая зона не блокирует приёмку.

## Capabilities

### New Capabilities

- `zone-forest-glade`: поляна с 5 огоньками, корнями, bounce-обучением, финалом пробуждения и тропинкой.

### Modified Capabilities

Нет обязательных delta к `core-movement` / `totoro-bounce` / `collectibles` (возможен тонкий hook на count==5).

### Dependencies

- `core-movement`, `totoro-bounce`, `collectibles`, `vertical-camera`.

## Impact

- `Clearing.unity`, арт корней/огоньков/тропинки, тонкий script финала.
- Без боя, инвентаря, tutorial UI, второй playable-сцены (пока).
