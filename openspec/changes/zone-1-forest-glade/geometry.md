## B. Относительная схема (вид сбоку, как у игрока)

Условные высоты, не чертёж в масштабе:

```text
        задний план: ствол + кроны
                    │
         ④ высокая ветвь / корень  ←── высокий отскок + смещение в воздухе
                    │
              ③ над спиной духа
           зона приземления после отскока
                    │
         ╔══════════════════════╗
         ║  СПЯЩИЙ ЛЕСНОЙ ДУХ   ║
         ║  широкий живот = bounce ║
         ╚══════════════════════╝
              │              │
         ② низкий корень    ⑤ корень за духом (к стволу)
              │
══════════════╧════════════════════ земля
 старт → ① огонёк у входа
```

| Элемент | Положение (относительно) | Назначение |
| --- | --- | --- |
| Старт | Левая нижняя часть | Безопасное появление |
| ○1 | Земля у входа | Обучение сбору |
| Низкий корень | Слева от духа | Обычный прыжок |
| ○2 | На низком корне | Проверка прыжка |
| Дух | Центр | Bounce |
| ○3 | Над верхней частью тела, **со смещением по X** | Первый отскок (не авто-центр) |
| Высокая ветвь | Выше и **в сторону** от точки отскока | Высота + air control |
| ○4 | На высокой ветви | Почти самый высокий |
| Корень за духом | К стволу, **в другую сторону по X**, чем ○4 | Финал маршрута |
| ○5 | На этом корне | Завершение сбора |

**Правило:** высокие огоньки **не** ставить строго друг над другом — нужен горизонтальный руль в воздухе.

## C. Координаты (компактно под bounce + задник без пустот)

База: земля **y=0**, дух **x=5**, spawn **x=1.2**, земля ширина **28**.  
Лимит: `airMaxSpeed` **4** → высокие ○ не дальше **~x 11.5**.  
`GladeBack` масштабируется под frustum камеры; целевой арт — **3840×2160** (`art.md`).

Корни: натуральный спрайт + тонкий **one-way** коллайдер.

### Платформы (`Ground` + PlatformEffector2D)

| Имя | center X | topY | Зачем |
| --- | --- | --- | --- |
| `ClearingGround` | 5 | 0 | ширина 28 |
| `RootLow` | **2.6** | **1.2** | обычный прыжок |
| `RootLand` | **7.2** | **3.2** | приземление после отскока |
| `RootHigh` | **9.0** | **7.0** | ○4 |
| `RootBehind` | **11.5** | **5.8** | ○5 |

### Огоньки (Collectible, спрайт `SeedGroundGlow`)

| ID | Имя | X | Y | Доступ |
| --- | --- | --- | --- | --- |
| ① | `Orb_Entrance` | **2.0** | **0.4** | ходьба |
| ② | `Orb_RootLow` | **2.6** | **1.5** | прыжок |
| ③ | `Orb_SpiritBack` | **6.4** | **4.5** | bounce |
| ④ | `Orb_HighBranch` | **9.0** | **7.35** | bounce + руль |
| ⑤ | `Orb_BehindTrunk` | **11.5** | **6.1** | bounce + руль |

### Финал

| Имя | Позиция | Когда |
| --- | --- | --- |
| `GlowPath` | **(13.5, 0.25)** | после 5/5 |
| Камера | bounds **(−2…15)**, y **13**, ortho **6** | |

Без лишнего декора.

### Маршрут

```text
старт (1.2) → ① (2.0) → RootLow+② (2.6)
  → дух (5) → bounce → ③ (6.4) → RootLand (7.2)
  → bounce → RootHigh+④ (9.0) / RootBehind+⑤ (11.5)
  → sequence → GlowPath (13.5)
```

### Проверки досягаемости

| Переход | Ожидание |
| --- | --- |
| Земля → RootLow (1.2) | обычный прыжок OK |
| Земля → RootHigh (7.0) | **нельзя** |
| Bounce → ○3 (4.5) | OK (пик ~11.8) |
| Bounce → RootHigh (7.0) при airMaxSpeed 4 | OK с рулём вправо |
| Bounce → RootBehind (5.8) | OK; сложность = X, не сверхвысота |

## D. Порядок работы в Editor

1. Временно кубы/Gizmos платформ по §C — без финального арта.  
2. Play: ○1–2 без bounce; ○3–5 только с bounce; с земли на RootHigh — нет.  
3. Поднять `boundsMax.y` до 13.  
4. Подставить спрайты корней/огоньков, сохранив topY и X.  
5. Не трогать `PlayerMovement` / `TotoroBounce` / collectible-логику.
