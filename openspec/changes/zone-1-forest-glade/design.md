# Design — Финальная лесная поляна со спящим лесным духом

Арт: [`art.md`](art.md) — переписать под огоньки / корни / тропинку.  
Геометрия для Unity: [`geometry.md`](geometry.md) — координаты без гадания.  
Канон геймплея — этот файл.

## 1. Цель зоны

Героиня на уединённой поляне. В центре спит огромный лесной дух. Разбросаны **пять золотых магических огоньков**.

**Задача:** исследовать → собрать все 5 (прыжки + отскок от живота) → пробуждение магии → открывается путь дальше.

**Цикл:**

```text
исследование → огоньки → корни → отскок от духа
→ все 5 → пробуждение → тропинка дальше
```

Не скорость и не пиксель-хантинг. Игрок сам пробует прыжки и открывает высоту.

## 2. Визуальная композиция (кратко)

| Элемент | Роль |
| --- | --- |
| Вход | Spawn, первый огонёк на земле |
| Спящий дух | Главный силуэт + `TotoroBounce` |
| Старое дерево + корни | Фон и платформы |
| Верхние корни/ветви | Высокие огоньки |
| Стена леса | Задник 2–3 экрана по ширине, запас по высоте под отскок |

Корни — читаемые платформы (округлый верх, мох), не перекрывают духа и огоньки.  
Стиль: рисованный 2D, тёплый свет, уют, без врагов и спешки.

## 3. Этапы геймплея

### Этап 1 — Появление

- Spawn у края поляны; камера на дух и дерево.
- Дух медленно «дышит» (лёгкий scale/offset), спит, не реагирует на вход.
- Огонёк 1 у входа — собрать без прыжка.
- Остальные видны: на низком корне, выше над телом, на высоких корнях.

**Прогресс:** 1/5. Цель этапа — понять пространство и цель без текста.

### Этап 2 — Низкий корень

- Огонёк 2 на невысоком корне-ступени.
- Обычный прыжок с земли.
- Камни/трава/мох подсказывают переход.

**Прогресс:** 2/5. Корни = платформы; отскок ещё не нужен.

### Этап 3 — Отскок от духа

- Огонёк 3 выше земли у верхней части тела; обычным прыжком не достать.
- Живот широкий и читаемый → игрок сам открывает bounce.
- Приземление: тело слегка сжимается, мягкий импульс вверх; дух **не просыпается** (ухо / тихий звук — опционально).

**Прогресс:** 3/5. Bounce заметно сильнее обычного прыжка.

### Этап 4 — Высокая точка

- Огонёк 4 на высокой ветви/корне у дерева.
- Осознанный отскок + руление в воздухе.
- Площадка достаточно широкая; промах → безопасная нижняя опора, повтор без наказания.

**Прогресс:** 4/5.

### Этап 5 — Последний огонёк

- Огонёк 5 на высоком корне у ствола, частично **позади** духа.
- Заметен с земли хотя бы частично.
- Тот же bounce; без ключей и переключателей.

**Прогресс:** 5/5. Порядок сбора не жёсткий, если геометрия позволяет.

### Этап 6 — Пробуждение (авто после 5/5)

1. Затишье (звук тише, дыхание стоп).
2. Пять огоньков собираются у героини облаком.
3. По очереди летят в дух, растворяются, золотой свет.
4. Ухо, глубокий вдох.
5. Приоткрывает глаз, поднимает голову — сонный интерес, не угроза.
6. Чих → золотая пыльца.
7. Поляна меняется: цветы, свечение, **светящаяся тропинка** в лес.

Событие **один раз**; во время sequence не триггерить повторный сбор.

### Этап 7 — Выход

- Дух остаётся (моргает / зевает / устраивается).
- Игрок замечает тропинку → идёт дальше.
- Если следующей зоны нет — тропинка = визуальный указатель; переход только по существующей архитектуре (одна сцена / placeholder).

## 4. Правила

- 5 огоньков через существующий `collectibles`.
- Земля + низкие корни = обычный прыжок; высота = bounce.
- Падение не сбрасывает собранное.
- Бесконечные попытки прыжков.
- Дух не просыпается от первого (и промежуточных) отскоков.
- Финал один раз после 5/5; тропинка остаётся.
- Все поверхности, огоньки и персонажи различимы.

## 5. Критерии готовности

1. Появиться и понять, что можно исследовать.  
2. Собрать огонёк на земле.  
3. Запрыгнуть на низкий корень, собрать второй.  
4. Открыть отскок от духа.  
5. Достать высокие огоньки.  
6. Собрать все пять без искусственных условий.  
7. Увидеть авто-пробуждение и преображение.  
8. Найти тропинку и понять направление дальше.

## 6. Принцип реализации (Unity)

**Сначала** сверить сцену и уже работающие системы, **потом** минимальные правки.

Использовать как есть:

- Движение / прыжок / воздух.
- `TotoroBounce`.
- Collectibles + tally.
- Камера, spawn, fall-respawn.

Не дублировать сбор, bounce, управление.

**Новое только если нет:**

- Расстановка 5 огоньков + корни-платформы.
- Реакция духа / финальная sequence на 5/5.
- Светящаяся тропинка (визуал ± простой trigger/marker).

## 7. Карта на текущий код

| Дизайн | Проект |
| --- | --- |
| Дух | `TotoroSleep` + `TotoroBounce` |
| Огоньки ×5 | `Collectible` (арт → золотой огонёк) |
| Низкий/высокие корни | новые спрайты + слой `Ground` |
| Дыхание / чих / пробуждение | пока нет — тонкий sequence-скрипт |
| Тропинка | новый спрайт + marker |
| Счёт 5/5 | `CollectibleTally` + listener на count==5 |

## Non-Goals

- Враги, урон, таймер, жёсткий порядок сбора.
- Текст tutorial / UI-подсказки.
- Вторая сцена для «дальше» (пока placeholder в той же `Clearing`).
